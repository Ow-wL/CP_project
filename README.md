## 데이터 파일
+ 버튼 문구는 기본적으로 `%APPDATA%\Copy_OwL\buttons.json`에 저장되며, 저장 위치는 프로그램에서 바꿀 수 있습니다.
+ 저장소에는 실제 사용 문구를 올리지 않습니다. 파일 형식은 `COPY/buttons.example.json`의 예시 문구를 참고하세요.
+ 설치 파일(exe)도 저장소에 포함하지 않습니다.
